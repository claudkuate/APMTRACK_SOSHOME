# APMTRACK API Contracts

Ce package contient les contrats publics partages entre le backend Rust, le back-office Angular et l'application Flutter.

Phase 1 expose `openapi.json` avec :

- les endpoints de sante ;
- l'authentification JWT ;
- les utilisateurs et roles ;
- les communes ;
- les agents ;
- la verification publique d'un agent par matricule.
